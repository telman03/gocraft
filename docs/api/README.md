# GoCraft API Documentation

This directory contains all API-related documentation and specifications for GoCraft.

## 📋 API Documentation

### Admin API
- [**ADMIN_DASHBOARD_API_GUIDE.md**](./ADMIN_DASHBOARD_API_GUIDE.md) - Complete admin dashboard API endpoints and integration guide

### OpenAPI Specifications
- [**swagger.json**](./swagger.json) - OpenAPI 2.0 specification in JSON format
- [**swagger.yaml**](./swagger.yaml) - OpenAPI 2.0 specification in YAML format
- [**docs.go**](./docs.go) - Generated Go documentation (auto-generated by swaggo/swag)

## 🚀 Quick Start

### Interactive API Documentation
When running the GoCraft server, you can access interactive API documentation at:
```
http://localhost:8080/swagger/
```

### API Endpoints Overview

#### Authentication Endpoints
- `POST /api/auth/register` - User registration
- `POST /api/auth/login` - User login
- `GET /api/auth/me` - Get current user info

#### Project Generation
- `POST /api/generate` - Generate new project
- `POST /api/validate` - Validate project configuration

#### Project History
- `GET /api/history` - Get user's project history
- `GET /api/history/{id}` - Get specific project details
- `GET /api/history/{id}/download` - Download project ZIP
- `DELETE /api/history/{id}` - Delete project from history

#### Admin Endpoints (Admin role required)
- `GET /api/admin/stats` - Get system statistics
- `GET /api/admin/users` - Get all users
- `PUT /api/admin/users/{id}/role` - Update user role

## 🔐 Authentication

All API endpoints (except registration and login) require JWT authentication:
```
Authorization: Bearer <your-jwt-token>
```

## 📝 API Development

### Updating API Documentation
1. Add Swagger annotations to your Go handlers
2. Run `swag init` to regenerate docs.go
3. The swagger.json and swagger.yaml files are auto-generated

### Testing APIs
- Use the interactive Swagger UI at `/swagger/`
- Import swagger.json into Postman or similar tools
- Check the admin API guide for detailed examples
