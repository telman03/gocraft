# 🗺️ GoCraft Roadmap

## Vision

**GoCraft aims to be the most comprehensive, developer-friendly Go microservice generator, enabling teams to build production-ready applications in minutes while following best practices.**

---

## 🎯 Current Status (v1.0)

### ✅ Completed Features
- **Core Generation Engine** - Template-based project scaffolding
- **3 Web Frameworks** - Gin, Echo, Fiber support
- **5 Database Types** - PostgreSQL, MySQL, SQLite, MongoDB, Redis
- **Authentication System** - JWT, OAuth2, user management
- **AI Integration** - OpenAI, Claude, OpenRouter APIs
- **DevOps Tools** - Docker, Makefile, Swagger documentation
- **Project History** - Track and manage generated projects
- **Admin Dashboard** - User and system management
- **Smart Validation** - Conflict detection and dependency resolution

### 📊 Platform Statistics
- **50+ API endpoints**
- **20+ supported features**
- **Production-ready templates**
- **Comprehensive documentation**

## 📅 Release Schedule

### Versioning Strategy
- **Major (x.0.0)** - Breaking changes, major features
- **Minor (x.y.0)** - New features, backwards compatible
- **Patch (x.y.z)** - Bug fixes, security updates

### Release Cadence
- **Major releases** - Every 6 months
- **Minor releases** - Monthly
- **Patch releases** - As needed (security, critical bugs)

### Upcoming Releases
- **v1.1.0** - Q1 2025 - Enhanced templates, GraphQL support
- **v1.2.0** - Q2 2025 - Observability stack, CLI tool
